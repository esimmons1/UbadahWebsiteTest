# UbadahWebsiteTest

This is a simple project where I'm trying to recreate an image from Ubadah Sabbagh's website. It's more of a personal test to practice and experiment with web development techniques.

## What It Does

- Attempts to replicate a specific image from Ubadah Sabbagh's website.
- Serves as a sandbox for testing HTML, CSS, and JavaScript skills.

## How to View It

You can view the project by opening the `index.html` file in your browser. No server setup is required.

## Why I Made It

I wanted to challenge myself to recreate a part of a real website to improve my web development skills. This project helps me understand layout, styling, and responsiveness.

## Stuff You Can Tweak

- Modify the HTML structure in `index.html` to change the layout.
- Adjust the styling in `style.css` to experiment with different looks.
- Add interactivity using JavaScript in `script.js`.
